# lit-arena 과목 개념과 레슨 스키마 v1.0

## 1. 사이트의 역할

lit-arena는 Arena 패밀리에서 **어학(국어·한자·영어)과 문학(국문학·세계문학)**을 맡는다.
외국어 습득은 lingua-arena가 맡으므로, lit-arena는 '말을 배우는 곳'이 아니라
**이미 쓰는 언어(국어)와 공용어(영어)를 깊이 이해하고, 그 언어로 쓰인 문학을 읽는 곳**이다.

| 과목 | 개념 | 학습자가 얻는 것 |
| --- | --- | --- |
| 국어 | 모국어 | 이미 쓰는 말을 설명하는 지식(문법·규범), 깊이 읽고 정확히 쓰는 능력 |
| 한자 | 국어의 주요 부분 | 한자어 어휘력과 조어 원리, 한문 고전을 읽는 문해력 |
| 영어 | 외국어이지만 세계 공용어 | 영어의 구조를 한국어로 이해하고, 영어로 된 지식을 읽고 논리적으로 쓰는 능력 |
| 국문학 | 국어로 쓰인 문학 | 고전·현대 한국 문학의 갈래, 흐름, 감상과 해석 |
| 세계문학 | 번역으로 읽는 세계의 문학 | 세계 문학사와 정전, 비교의 눈 |

## 2. lingua-arena와 겹치지 않게 나누는 기준

같은 '한국어', '영어'라도 두 사이트는 목적, 학습자, 평가가 다르다.

| | lingua-arena | lit-arena |
| --- | --- | --- |
| 한국어 | **한국어(KFL)**: 외국인이 한국어를 배우는 외국어 과정. 의사소통 숙달 | **국어**: 한국어 모국어 화자가 국어를 탐구하는 과정. 문법·규범·독해·작문 |
| 영어 | **영어(외국어)**: 말하고 쓰는 의사소통 능력 습득 | **영어(공용어)**: 영어의 구조·어휘·역사를 이해하고, 학술·공적 텍스트를 읽고 쓰는 문해력 |
| 레벨 | CEFR A1~C2 6단계 | Arena 공통 3단계(레벨1 고교, 레벨2 전문대, 레벨3 대학) |
| 설명 언어 | 목표 언어 + 영어 설명(이중 언어 필드) | 한국어 (영어 과목도 설명은 한국어, 예문·지문은 영어) |
| 학습 방식 | 과제 중심(쓰기 2 + 말하기 2 / 유닛) | 설명-문제가 번갈아 나오는 레슨(math·sci·socio-arena와 같은 방식) |
| 평가 | 말하기·쓰기 루브릭 채점 | 빈칸·수치·순서·서술형 자동 채점, 말하기 평가 없음 |
| 한자 | KFL C1~C2에서 어원 보충 설명(선택) | 독립 과목(한자Ⅰ·Ⅱ). 국어 어휘의 뿌리로 체계적으로 학습 |
| 문학 | 언어 트랙별 **원어로 읽는** 지역 문학(B2 이상, 지역학) | **한국어로 읽는** 국문학과 번역 세계문학, 문학사·갈래론 |

정리하면:
- lingua-arena에서 '국어 과정을 별도로 만든다'던 구상은 lit-arena의 국어Ⅰ·Ⅱ가 맡는다. lingua-arena의 KFL 트랙은 그대로 둔다.
- lingua-arena의 '한자와 고전 문해력 기초' 세부과목 구상은 lit-arena 한자Ⅰ·Ⅱ로 옮긴다.
- 영어 과목은 회화·발음·CEFR 레벨을 다루지 않는다. 영어로 '무엇을 읽고 쓰는가'에 집중한다.
- 세계문학은 번역본 기준 문학사·작품론이다. 원어 강독은 lingua-arena 각 언어 트랙에 남긴다(링크로 연결).

### lingua-arena 지역학 트랙과의 관계
- lingua-arena는 어학(CEFR A1~C2) 숙달 축과 별도로 '지역학 트랙'(Arena 레벨2·3, 대학 수준)을 둔다. 지역학에는 레벨1이 없다.
- 지역학 레벨2 진입: 언어 B1~B2 + socio-arena 세계사·지리, lit-arena 세계문학 레벨1. 레벨3 진입: 언어 C1 이상 + 지역학 레벨2.
- 역할 구분: lit-arena 세계문학 = 번역으로 읽는 세계 문학사(여러 지역 비교), lingua-arena 지역학 = 원어로 읽는 한 지역의 언어·문학·역사·사회(한 지역 심화), socio-arena = 세계사·지리 일반. socio-arena 레벨3 '지역사'는 지역학 트랙과 공유 과목으로 연결한다.

## 5. 작품 인용 원칙 (저작권)

- 고전 문학, 한문 원전, 저작권이 만료된 작품: 원문 인용 가능. 출처(작품명·작가)를 적는다.
- 저작권이 살아 있는 현대 작품(대체로 사후 70년 이내 작가): 전문이나 긴 구절을 싣지 않는다. 줄거리·구조·표현 기법을 설명하고, 꼭 필요하면 한두 행 이내로만 쓴다.
- 번역 세계문학: 번역문도 저작물이므로 직접 번역하거나 요약한다.

## 6. 레슨 파일 (socio-arena·sci-arena·math-arena 스키마 v1.0과 같음)

경로: content/level1/{course}/ch{NN}/l{NN}.json
- 코스 목록: content/level1/courses.json (available로 공개 여부 표시)
- 코스 요약: content/level1/{course}/course.json (tools/make_course_index.py가 생성)
- 챕터 목록: content/level1/{course}/ch{NN}/chapter.json, 챕터 복습: review.json
- tags.domain: ["국어"] 등 과목 태그, tags.region = KR, tags.curriculum = 2022-high
- screens: stage = intro | discover | summary | apply
- 분량 기준: 레슨당 화면 20~24개, 문항 15~17개, 예제 3개, 챕터 복습 10문항(모든 레슨에서 출제)

화면 유형
- explain: title, body(문단 배열)
- example: problem, steps(풀이 단계), answer
- question: fill_blank(허용 표기를 answers에 모두), numeric, ordering, written(rubric.keyword_groups 중 min_groups_matched개 이상)
- 공통: hint(적용·복습 문항은 필수), explanation(20자 이상)

과목별 문항 작성 메모
- 한자: 한자 자체를 입력하게 하는 문항은 피하고 음·뜻·한자어를 한글로 답하게 한다(입력기 부담). 한자는 지문과 풀이에 보여 준다.
- 영어: 설명은 한국어, 예문과 정답은 영어. 정답 허용 표기에 축약형(don't / do not)을 함께 넣는다.
- 문학: 감상형 문항은 written으로, 갈래·작가·작품·표현 기법은 fill_blank로.

## 채점 정규화
- 공백, 가운뎃점(·ㆍ), 따옴표·낫표를 무시한다
- 괄호 속 한자 병기를 무시한다 ("음운(音韻)" = "음운")
- 영문은 대소문자를 구분하지 않는다

## 빌드
```
python3 tools/build_c1_ch01.py content   # 코스·챕터마다 (c1, c2 / ch01~ch08)
python3 tools/lint.py content            # 서술형 채점 기준·정답 노출 검사
python3 tools/make_course_index.py content
python3 tools/gk.py                      # guides.json 갱신
python3 tools/make_guide.py              # 플레이어를 고친 뒤 guide.html 다시 생성
python3 tools/check_facts.py content     # 바뀔 수 있는 값 점검
```
- tools/sk.py: 저장 전에 문항·화면·예제 수, 풀이 길이, 힌트, 빈칸 수, 복습 출처를 검사한다
- tools/c{코스}common.py: 코스 공통(복습 문항의 source_lesson 지정)
- 국어Ⅱ의 읽기 지문과 쓰기 예문은 모두 레슨을 위해 새로 쓴 글이다. 사회 챕터의 통계 수치는 가상 자료로 표시했다
- 바뀔 수 있는 값(어문 규범 개정, 교육용 한자 목록, 문학상 현황)은 tools/facts.py에만 쓰고 F()·V()로 가져온다
